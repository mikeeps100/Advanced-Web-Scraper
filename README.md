# 📈 Crypto Grid Trading & Technical Analysis Bot (Python)

An automated Python trading bot configured to execute strategic grid trading orders and track technical analysis indicators (RSI, MACD) via direct API websockets.

---

## 🚀 Key Features
*   **Automated Grid Strategy:** Places buy/sell orders automatically based on custom price corridors.
*   **Technical Indicators:** Computes real-time RSI, MACD, and Moving Averages for smart market entries.
*   **Risk Management:** Built-in hard stop-loss and take-profit loops to protect trading capital.
*   **Paper Trading Mode:** Test your strategies in a 100% safe simulation network (Testnet) before risking real funds.
